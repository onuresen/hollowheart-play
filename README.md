# Hollowheart: Heart of the Mountain — Beta (Act I)

A cozy mining-and-alchemy shop game with a story underneath.
Dig a falling-pixel mine, brew and craft, sell to heroes, and find out where Rinne went.

**Play in your browser:** https://onuresen.github.io/hollowheart-play/

- Beta: Act I only. Things will change.
- Saves stay in your browser. Nothing is sent anywhere.
- Best with a keyboard or a gamepad. Sound on.
- Romance is suggestive, never explicit. All characters are adults.

This repository holds only the built game. The source is private.
